# FleetFlow — Video Style Website

A responsive fleet-management landing website recreated from the supplied reference video style.

## Run
Open `index.html` in a browser. No server is required.

## Included
- Responsive landing page
- Fleet dashboard mockup
- Mobile fleet/inspection mockup
- Vehicle, fuel and maintenance sections
- Reference video player using `assets/fleet-demo.mp4`
- Supplied video screenshots used as visual references
- CSS animations and responsive layout

## Files
- `index.html` — page structure
- `style.css` — complete styling
- `script.js` — scroll reveal animation
- `assets/` — reference images and supplied demo video
